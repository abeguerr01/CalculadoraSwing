# Proyecto Java Swing

## ¿Que es este repo?
Este repositorio es mi primer proyecto hecho con java swing, en el cual aprendo a crear ventanas, mostrarlas realizar acciones sencillas como la extraccion de texto de un campo de texto, mostrar mensajes emergentes, etc.

## Ventanas
Este proyecto tiene 3 ventanas:
- La primera es la ventana principal, la cual te permite acceder a las otras dos.
- La segunda es una ventana de calculadora, la cual te permite realizar operaciones combinadas y calculos con grados.
